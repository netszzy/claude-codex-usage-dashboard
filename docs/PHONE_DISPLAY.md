# iPhone 外接屏模式

## 目标与边界

旧 iPhone 作为本项目的常亮横屏，只显示额度摘要；它不是电脑的 USB 副屏，也不会读取凭据、会话正文或配置写入接口。

原桌面 HUD 服务继续只监听 loopback。手机入口是单独的 HTTP 服务，只有显式使用 `start-dashboard-phone.bat`（或设置 `PHONE_DISPLAY=on`）才会启动。

```text
本机采集器 ──> 127.0.0.1:8787 桌面 HUD / 原有 API
                    │
                    └──> 0.0.0.0:8788 手机只读显示服务（镜像同一 API 响应）
                               │
                         私有 Wi-Fi + 配对 Cookie
                               │
                            iPhone Safari
```

## 首次连接

1. 双击 `start-dashboard-phone.bat` 启动看板。若桌面看板已在运行，脚本会使它重启到手机模式；无需先手动退出。
2. Windows 第一次询问网络访问时，只允许“专用网络”；不要勾选公用网络。
3. 右键托盘图标，选择“手机外接屏…”。
4. 让 iPhone 和电脑连接同一可信 Wi-Fi，在 Safari 打开列表中与手机同网段的 `http://<IPv4>:8788/phone/`。
5. 输入托盘中显示的 12 位配对码。成功后用 Safari 分享菜单“添加到主屏幕”，以后从主屏幕直接打开即可。

电脑有 RayLink、GameViewer 或 VPN 虚拟网卡时，托盘会列出多个私网地址。这是正常的；选择与 iPhone Wi-Fi 子网相同的地址即可。

## 显示行为

- 手机端只读，严格同步桌面当前勾选的 Agent 与顺序；自定义 Agent 也会同步，且不会截断为前三项。
- 横屏时按可用宽度排列卡片；普通 Agent 显示全部额度窗口。带模型分组的 Agent（如 Antigravity）会完整显示每个模型组及其额度、百分比、细进度条和重置倒计时；极小高度下可在该卡片内滚动，绝不截断数据。
- 桌面与手机页面在可见时都每 5 秒检查一次；手机服务只镜像桌面 API 的同一份响应，不会独立采集，从而不会出现两端数据源先后不一致。页面只在 ETag 或分钟级倒计时变化时更新 DOM；原有采集器仍负责上游服务自己的刷新节流。
- 建议 iPhone 低亮度、深色主题、接电，打开“自动锁定：永不”和“引导式访问”。
- 托盘“手机外接屏”状态为“已就绪”时，表示本机已确认服务端口可响应；若仍无法从手机打开，请检查 Windows 防火墙是否仅允许“专用网络”。

## 安全设计

- 服务只接受来自 RFC1918 私网或 loopback 的 IPv4 客户端，不接受公网地址。
- 首次连接需要约 60 bit 随机配对码；连续五次失败后，该来源十分钟内不能继续尝试。
- 配对成功后通过 `HttpOnly`、`SameSite=Strict` Cookie 保存 1 年会话；额度 API、页面资源均要求该 Cookie。
- 配对密钥仅保存在 `%USERPROFILE%\.claude-codex-usage-dashboard\phone-display.json`，不应提交、截图或发送给他人。
- 手机入口没有 `/api/config`，因此不能修改看板阈值、桥接开关或任何本机文件。
- 入口使用本地 HTTP，适合受信任的家庭私网；不要在公共、访客或不可信 Wi-Fi 上开启。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PHONE_DISPLAY` | `off` | `on` 启动局域网手机入口；`off` 保持原有纯本机模式。 |
| `PHONE_DISPLAY_PORT` | `8788` | 手机入口端口，范围 1～65535。 |
| `PHONE_DISPLAY_HOST` | `0.0.0.0` | `0.0.0.0` 对私网设备开放；`127.0.0.1` 仅用于本机调试。 |
| `PHONE_DISPLAY_SOURCE_PORT` | 当前桌面服务端口 | 仅在把手机服务单独运行于其他端口时使用；指定其应镜像的桌面 API 端口。 |
| `PHONE_DISPLAY_CONFIG_PATH` | `~/.claude-codex-usage-dashboard/phone-display.json` | 配对码与会话令牌的私有本机文件。 |

如果需要废弃已配对的手机，在看板退出后删除该私有配置文件并重新启动手机模式。下次启动会生成新的配对码；这会使旧 Cookie 失效。
