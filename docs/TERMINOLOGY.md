# 界面术语表

界面采用“中文说明 + 稳定状态符号”的写法：中文负责解释，英文缩写便于快速扫视和在截图、日志中保持一致。

| 界面文字 | 含义 | 使用规则 |
| --- | --- | --- |
| LIVE · 实时 | 数据在其新鲜度阈值内，且最近一次读取没有错误。 | 绿色状态点；可附“刚刚 / N 分钟前”。 |
| STALE · 已过期 | 仍有上一次有效配额，但已超过数据源的有效期。 | 黄色状态点；不推算或伪造新的重置周期。 |
| OFFLINE · 离线 | 最近一次读取或刷新失败。 | 红色状态点；保留可用的历史值时仍明确标为离线。 |
| 等待快照 | 尚未读取到该 Agent 的任何可用额度。 | 不把它误标为错误或零用量。 |
| 5H | 5 小时滚动配额窗口。 | 仅在数据源确实提供该窗口时显示。 |
| 7D | 7 天滚动配额窗口。 | 仅在数据源确实提供该窗口时显示。 |
| 重置 | 到该额度窗口下一次重置的剩余时间。 | 无可靠时间时显示“无重置时间”；过期时显示“已到期”。 |
| 使用率 | 已用额度占该窗口总额度的百分比。 | 告警阈值可在设置中设为 50%～95%。 |

“连接中”只用于首次请求尚未完成；“未选择 Agent”表示用户主动隐藏了全部卡片。两者都不是数据源故障。
